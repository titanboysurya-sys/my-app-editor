# AGENTS.md

## Scope

These instructions apply to the entire workspace.

## Working practices

- Inspect the existing files and repository state before making changes.
- Preserve unrelated user changes; do not reset, overwrite, or delete work without explicit approval.
- Use `apply_patch` for manual file edits.
- Keep changes focused on the requested task and use plain, maintainable code.
- Run relevant tests, linters, or validation commands after making changes. If none exist, say so.
- Report what changed, what was verified, and any remaining limitations.

## Safety

- Do not commit, push, publish, or make external changes unless explicitly requested.
- Confirm exact targets before destructive operations.
- Ask for clarification when a required decision would materially change the implementation.
